# Assets Directory

This directory contains the application assets:

- `icon.png` - App icon (1024x1024 recommended)
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `favicon.png` - Web favicon
- `chime.mp3` - Sound effect for bus signal feedback

## Note
In a production environment, you would replace these placeholder files with actual assets.
For the audio file, you can use any short chime sound (e.g., a simple beep or notification sound).
